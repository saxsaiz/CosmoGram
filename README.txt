TELEGRAM WEB APP — IP CHECK

Назначение:
1. Пользователь открывает Web App из кнопки «🔐 Проверка аккаунта».
2. Сервер проверяет подпись Telegram initData.
3. Сервер получает IP подключения и сохраняет только salted SHA-256 хеш.
4. Если хеш уже принадлежит другому Telegram ID, текущий аккаунт блокируется.
5. Бот и Web App используют ОДНУ SQLite БД, поэтому бан сразу виден боту.

ВАЖНО:
Совпадение IP — не доказательство, что два аккаунта принадлежат одному человеку.
Один IP могут одновременно использовать семья, школа, общественный Wi‑Fi,
мобильная сеть, VPN/прокси и т.д. Поэтому такая проверка может давать ложные блокировки.

Установка:
1. Python 3.11+.
2. pip install -r requirements.txt
3. Запусти Web App на том же сервере/диске, где находится tenx_gram.db бота,
   либо укажи BOT_DB_PATH на общую БД.
4. BOT_TOKEN должен совпадать с токеном бота.
5. IP_HASH_SALT должен быть одинаковым/стабильным для Web App. Никому его не публикуй.
6. Нужен публичный HTTPS-адрес.
7. В limegram777.py укажи этот адрес в WEBAPP_URL.

Переменные:
BOT_TOKEN=токен_бота
BOT_DB_PATH=tenx_gram.db
IP_HASH_SALT=случайная_длинная_строка
TRUST_PROXY=1   # если перед Flask стоит доверенный reverse proxy
PORT=5000

Если Flask доступен напрямую из интернета без reverse proxy, поставь TRUST_PROXY=0,
чтобы не доверять поддельному X-Forwarded-For.

Запуск:
python app.py
